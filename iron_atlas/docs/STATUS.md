# IRON ATLAS: SHATTERED WORLD — Stage 1 Status

Date: 2026-10-28 · Branch: `arena/7464ca7a-videos-motion` · Suite: **4/4 passed (119 checks)**
Engine target: Godot 4.x (verified on 4.7.2 via the wasm headless harness in `pixel_pirates/tools/godot_node`).

## What Stage 1 delivers (vertical slice, playable end-to-end)

Boot → main menu → campaign setup (seed/name/scenario) → strategic world map with
pausable real-time clock → recruit/purchase/move/hold orders → real-time pausable
tactical battle → losses flow back to the strategic layer → day/week ticks drive
supply, economy, diplomacy, AI → autosave-friendly versioned saves (3 slots).

Loop verified by `tests/run_all.gd` (59 logic checks), `tests/test_ui_flow.gd`
(12 scene-UI checks), `tests/test_tactical.gd` (5 battle checks) and
`tests/selfplay.gd` (43 checks: 240-day unattended sim — AI fights, economy moves,
saves round-trip, no crash).

## Implemented (real, exercised by tests)

- **Core**: 4 autoloads only — `EventBus` (signals), `GameState` (owns `cs` +
  system instances), `CampaignClock` (speeds 0/1/2/4, pause, per-day/week emits),
  `SaveManager`. All systems are `RefCounted`, typed against `CampaignState`, and
  contain zero rendering/input code → simulation is fully decoupled and testable.
- **CampaignState** (`core/campaign_state.gd`): dict-of-dicts with stable ids
  (`reg_NN`, `cty_*`, `frm_NNNN`, `ord_NNNN`), persisted `rng_state`
  (`st.randf()`), version field, query helpers (`formations_of/in`,
  `player_id`, `next_id`).
- **World generation** (`world/world_generator.gd`): deterministic seeded gen —
  continents, regions (count configurable via scenario data), terrain/climate
  bias, neighbors (land adjacency), cities/farms, countries, starting formations.
  Validation pass rejects degenerate worlds (disconnected graph, empty owners).
  Scenario data: `data/scenario_vardena.json` (Phase A — Republic of Vardena
  underground org, ~60 fighters split into 2 formations + enemy garrisons),
  `data/equipment.json` (catalog with cost/combat/supply figures).
- **Military** (`military/`): `CommandSystem` (move/hold/recruit orders, BFS
  paths, per-day progress with terrain & supply speed modifiers, region control
  flips on arrival), `CombatSystem` (hostile pairs from relation threat, engagement
  resolution from class/equipment/count/supplies/morale/terrain factors,
  post-battle losses, 0.25 capture chance).
- **Tactical layer** (`scenes/tactical_map.*`): 30×20 tile grid generated from the
  region's terrain+seed, tactical units spawned per strategic formation
  (class/equip/count → hp), move costs per terrain, reach/fire with combat-factor
  damage, morale decay, pause + speed, click select / right-click orders, sprite
  rendering, result applied proportionally back to strategic formations, auto
  return to the world map.
- **Logistics** (`logistics/supply_system.gd`): supply graph from farms/cities via
  BFS over owned/linked regions; linked formations regenerate
  (+0.10·ratio+0.05/day), isolated formations attrit (−0.05−0.05·(1−ratio));
  low supplies halve movement and degrade combat factors.
- **Economy** (`economy/`): `EconomySystem` (treasury, weekly tax from regional
  output·stability, equipment upkeep, debt interest, reconstruction spend),
  `MarketSystem` (catalog from data file, quotes with diplomatic-price modifiers,
  purchase with delivery eta, equip-from-inventory, recruit costing).
- **Diplomacy** (`diplomacy/diplomacy_system.gd`): multi-dimension relations
  (threat/trust/grievance/trade), opinion drift per week, war/ceasefire/trade-pact
  treaty objects with duration and expiry effects, relation-gated market prices.
- **Intelligence**: imperfect information — enemy formation strength shown as
  estimate bands scaled by intel coverage; fog on unowned-region stability.
- **AI** (`ai/faction_ai.gd`): weighted-utility decisions per week using the SAME
  systems and rules as the player (issues real orders through `CommandSystem`,
  recruits/purchases through economy/market, declares war/ceasefire through
  diplomacy). Selfplay shows it attacking, expanding and negotiating unattended.
- **Persistence** (`persistence/save_system.gd`): versioned JSON to
  `user://saves/slot_N.json`, migration hook table, autosave on week tick,
  round-trip verified in tests (day/treasury/positions/orders preserved).
- **UI** (`scenes/`): boot, main menu, campaign setup (seed field), world map —
  procedurally drawn data-driven map (no static image; regions as nodes with
  terrain colors, borders, selection, order targeting), dock with Region /
  Formations / Market / Diplomacy / Intel / Economy panels, notifications,
  engage button → tactical map, pause/speed controls.
- **Art**: deterministic pixel-art sprites generated by `tools/make_sprites.py`
  (7 unit classes + 9 terrain textures, palette coherent with the supplied
  references; committed under `assets/sprites/`).
- **Tests/tooling**: `tools/run_suite.sh` runs all four suites headless on the
  wasm Godot harness and prints `SUITE: n passed, m failed`; test protocol is
  `TESTS: PASS: n checks` / exit code.

## Simplified (deliberate Stage-1 scope)

- 24 regions / 4 countries in the Vardena scenario instead of 200+ (generator is
  count-configurable; scaling is a Stage-2 data + chunking/culling task).
- Phases B–E (regional control → civil conflict → government formation →
  international era) exist as scenario-data hooks and diplomacy dimensions, not
  as a scripted phase-progression director yet.
- Research/industry: equipment tiers + reconstruction spending only; no tech tree.
- Dynamic event engine: weekly opinion drift + notifications; no scripted
  event deck / campaign director pacing.
- Maritime: coast terrain + naval unit class exist in data; no sea-lane logistics.
- Tactical battles resolve by attrition skirmish (shared combat factors), no
  facing/flanking geometry beyond terrain reach and move costs.
- Intel is coverage-scaled estimates, no spy-network gameplay.
- World map draws vector/pixel hybrid procedurally; sprite-per-region texturing
  of the strategic map is Stage 2 polish.

## Known constraints (harness)

tests), `.png` loading unavailable headless (sprites committed; visual checks are
manual/editor-side), scene tests run with `--fixed-fps 60` and phase assertions
across frames because `_ready` is deferred to the first main-loop iteration in
`-s` script mode.
