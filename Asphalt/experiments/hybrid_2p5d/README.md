# Hybrid 2.5D experiment

This is an isolated A/B rendering experiment, not a replacement for the existing
3D gameplay project. Open `scenes/experiments/hybrid_2p5d_benchmark.tscn` in
Godot 4.2.2, or capture it with:

```bash
CAPTURE_SCRIPT=res://tools/capture_hybrid_benchmark.gd ./tools/capture_benchmark.sh
GODOT=/path/to/godot-4.2.2 ./tools/run_hybrid_tests.sh
```

Assets are generated by `tools/generate_hybrid_assets.py`. See
`docs/05-rendering-strategy-review.md` and `docs/06-hybrid-2p5d-benchmark.md`
for the evaluation, screenshots, metrics, test results and recommendation.
