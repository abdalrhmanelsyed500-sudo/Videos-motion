## Technical decisions

1. **Godot 4.2 + GDScript** — verified against the installed editor; no uncertain 3.x/4.x API mixing.
2. **Procedural low-poly assets** — every mesh has a known scale, pivot and material. Motorcycles are assemblies of wheels, frame tubes, tank, seat, engine, exhausts, lights and steering parts; riders are articulated figures with distinct silhouettes.
3. **Continuous spline-like road** — `AGRoadPath` defines centerline, elevation, lanes and progress; `AGRoadBuilder` generates a continuous mesh, markings, barriers and matching trimesh collision.
4. **Gameplay-first arcade physics** — `CharacterBody3D` with speed, gear/RPM, speed-sensitive steering, lean, boost, wobble and collision impulses. Traffic/rivals use deterministic lane logic rather than baked navigation.
5. **Single persistent state** — `GameState` autoload stores roster, bike selection, settings, unlocks and results. `Main.gd` owns screen flow; `RaceWorld.gd` owns one race.
6. **Retro rendering by construction** — flat albedo, coarse textures, one directional light, procedural sky, low geometry density, and a physical dashboard drawn from live state.
7. **Generated audio** — engine, siren, impacts, countdown, menu, hospital and victory WAVs are original procedural placeholders, documented as such.

## Main risks and mitigations

- **No high-fidelity models**: silhouette, proportion, functional pivots and material readability take priority over polygon count.
- **No real GPU/display in sandbox**: logic tests use headless; actual screenshots use software Mesa. If capture fails, the project still ships with reproducible capture scripts and the test report records the limitation honestly.
- **Scope vs. quality**: complete loop first, then roster and environment density. Each system has a narrow responsibility.
- **Arabic typography**: the title and signs are rasterized with a free font; functional labels use Latin text to avoid runtime shaping dependencies.
- **Audio**: generated tones are clearly labeled as placeholders; no copyrighted sounds are included.
